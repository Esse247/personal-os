# PERSONAL OS — Foundation v0.1

PERSONAL OS is a secure, model-agnostic personal and household operating-system foundation. This phase is a local demonstration only: all people, calendar data, transactions, providers, and actions are synthetic or mocked.

The source-of-truth entry point is [`PROJECT_MANIFEST.yaml`](PROJECT_MANIFEST.yaml). Setup and demonstration commands are documented in [`docs/INDEX.md`](docs/INDEX.md).

Nothing in this repository connects to a live bank, calendar, email service, health account, wearable, payment system, or production model API.
